# Halo Voice Canvas

Create the HALO Web application UI based strictly on the attached HALO references and assets.

HALO is a premium multimodal AI assistant. Use the attached HALO assets as the canonical visual assets whenever applicable. Do not replace HALO-specific icons, logo, Orb, or graphics with generic icons or generated substitutes.

Start with the Voice screen only. Reproduce the attached Voice reference as accurately as possible, including its layout, proportions, spacing, typography, dark cosmic background, glassmorphism surfaces, luminous borders, blue/violet neon glow, HALO Orb, status indicators, activity panel, suggestion cards, recent items, command bar, header, drawer/menu behavior and bottom navigation.

The attached HALO drawer reference defines the navigation structure and visual language for the modules.

Make the interface responsive for desktop, tablet and mobile while preserving the visual hierarchy of the reference.

Build the UI with reusable components and design tokens so that the same HALO design system can later be applied to Chat, Vision, Documents, Translate, Music, Images, Memory, Profile, Plans and Settings.

Do not build all the other screens yet.

Do not add backend, authentication, database or real AI functionality yet.

Focus on creating a high-fidelity, polished HALO Voice UI and the reusable foundation needed for the rest of the application.
